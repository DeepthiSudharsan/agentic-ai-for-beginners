## What to expect

This is the complete flow: Finley may load a skill, invoke a Python tool, invoke a specialist, or invoke the MCP comparison tool. The terminal shows those activity lines before the final answer. Answers should stay within the supplied fictional Northstar data and say when a requested fact is unavailable.
