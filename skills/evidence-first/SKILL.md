# Evidence-first skill

When this skill is loaded:

1. Use only the facts supplied by the assistant.
2. Include the source attached to the fact when one is available.
3. Separate a fact from an interpretation.
4. If the answer is not present, say that the dataset does not contain it.
5. Never invent a market price, forecast, or financial recommendation.
