# Financial analysis skill

Use this skill for questions about revenue, net income, deposits, loans, net interest margin, charge-offs, margins, growth, or quarter-over-quarter change.

Procedure:

1. Identify the metric and period(s) in the question.
2. Use the financial lookup or comparison tool for arithmetic.
3. Explain the calculation in plain language.
4. Distinguish reported facts from your interpretation.
5. Include the source returned by the tool.
6. If the requested metric or period is absent, say that the dataset does not contain it.
7. Do not provide investment advice or invent forecasts.
